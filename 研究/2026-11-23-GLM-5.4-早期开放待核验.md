# 2026-11-23 GLM-5.4：Loop Transformer 与订阅渠道正式开放

> 2026-11-24 复校：已取得 11 月 23 日官方技术公告及产品文档，取代昨日仅有二手信号的判断。订阅发布已获官方确认；标准 API 与权重尚非 GA。

## 事件与产品边界

2026-11-23，智谱发布 GLM-5.4，首个采用 Loop Transformer 的旗舰型号。官方列出 Coding Plan、ZCode、Z.ai Chat 为体验入口；标准 API 标为 Coming Soon，权重拟在安全加固后开放。[1] 同日 AutoClaw 公告确认接入。[2] 精确上线时刻、地区覆盖及实际授权调用未独立验证。

| 项目 | 官方资料与边界 |
|---|---|
| 架构 | 750B 级基座中 28 层共享权重循环两次；不将有效计算深度当成新增参数 |
| 技术 | 每 token 门控残差更新；跨循环共享稀疏 KV 与独立局部滑窗；复用稀疏注意力索引 |
| 上下文 | ZCode 文档 1M，约 966K 自动压缩；不是全程无损记忆证明 |
| 模态 | 官方描述视觉能力及视觉 coding；完整 API 输入输出规格待公布 |
| 推理 | Low/High/Max，默认 Max；厂商承认过长思考问题 |
| 速度 | 厂商报告非高峰最高 200 token/s，高峰 70–80；非独立吞吐测试 |
| 访问 | Lite/Pro/Max/Team 及体验套餐；第三方兼容 Coding Plan 工具可选 glm-5.4，Claude Code 可用 glm-5.4[1m] |
| 额度 | 现行套餐相同额度可消耗 GLM-5.3 的 1.5 倍 token；旧 V1 不享受此变化；不是所有用户周额度普涨，也不是 ZCode 额外促销 |
| 默认切换 | 官方 FAQ 称 5.3 仍可用，不自动换成 5.4 |
| API 价格 / 权重 / 许可证 | 尚未公布可核验标准 API 价格；权重为未来计划，许可证未定 |
| Agent | ZCode 文档描述目标循环、工具调用、浏览器/电脑控制与闲时任务；属产品文档声明，未独立验证可靠性 |

## 评测与使用体验

官方报告 30B 同参数消融实验约增加 10% 训练计算，若干评测输出长度减少 10–14%；不能把这一结果直接外推为 750B 旗舰节省同等成本。厂商称能力可比 2–3T 模型，并展示视频、游戏、CAD、3D shader；这是厂商实验和 demo，不是独立榜单或生产结果。[1]

官方 FAQ 明确回应思考时间长、额度消耗快的问题，并建议简单任务降低 effort。[3] 这是厂商承认的使用限制，不是用户样本统计。TestingCatalog 11 月 23 日报道复述发布及架构，[4] OrcaRouter 比较文章未提供 GLM-5.4 同条件实测。[5] 尚无可重复独立 benchmark 或代表性社区共识；不能断言性能领先、实际延迟下降或任务成本下降。

## 竞争背景与史义

与近 30 天在途研究 #89 Qwen4-Max、#91 GPT-6.2、#92 Gemini 4 Neon 对照：这些研究涉及商业 API 分层，而 GLM-5.4 先从订阅渠道交付。更值得跟踪的是参数规模与共享层计算深度的两条 scaling 路径，以及订阅额度、推理 effort 与实际成功任务成本之间的关系。不能以参数或 token 单价直接推断竞争胜负。
