## 竞争背景与入史意义

过去 30 天前沿模型竞争持续朝 coding/Agent、视觉、长上下文、订阅配额与 API 计价分层发展。若本次 Coding Plan 开放获官方核验，即便没有权重与标准 API，也应按**有实际使用意义的新型号及访问政策变化**留档；但不能与已完成标准 API 上线的型号直接进行价格/吞吐比较。尤其应追踪“型号目录可见 → 订阅可选 → API 成功调用 → 公开定价 → 权重开放”的实际时间差。
