# 2026-11-16：Qwen4-Max 正式 API 可用——Qwen4 旗舰、价格与 Agent 能力

> 增量研究包；初录 2026-11-16。先校核事件日期与来源等级，再决定编年整合。**不是开放权重发布，也不是独立生产可靠性验收。**

## 事件与日期
- **2026-11-11 10:00（UTC+8）**：`qwen4-max-preview` 开始 Token Plan 限定预览；官方规定预览至 11-25 24:00，届时该预览型号退役。此时**不能**视为按量付费 API GA。[^3]
- **2026-11-16**：阿里云发布 Qwen4-Max 正式公告；Model Studio 文档同日更新，正式型号 `qwen4-max` 提供 API 与 Token Plan 访问。Reuters 11-16 报道称公司于周日公布模型，须区分媒体所指周日的对外披露与 11-16 官方公告/GA 文档；未取得精确到小时的正式 API 上线日志，不反推上线时刻。[^1][^2][^4]

## 核心事实（截至 11-16）
- **架构/规模**：厂商披露稀疏 MoE，**2.4T 总参数、71B 每 token 激活**；并非公开权重。厂商称之后将发布较小的 Qwen4 开放权重型号，**尚未有权重与许可证**，不能写成 Qwen4-Max 可自部署。[^1]
- **模态与上下文**：文本/图片/视频输入，文本输出；1,000,000 tokens 上下文；非思考最多输入 991,808、输出 131,072 tokens；思考模式最多输入 983,616，思考+答案合计最多 262,144 tokens。[^2]
- **推理/工具**：默认开启 thinking（`reasoning_effort=high`，默认 budget 131,072），支持 low/high/xhigh；function/parallel tool calling、结构化 JSON、联网搜索、显式/隐式缓存、推理摘要及加密状态回传。支持 OpenAI Chat Completions/Responses、Anthropic Messages、DashScope 兼容接口。**协议兼容不等于所有 harness 无缝可靠运行。**[^2]
- **访问/部署**：QwenCloud、阿里云 Model Studio API、Token Plan 及 QwenWork/QwenStudio；官方列出北京、新加坡、法兰克福、弗吉尼亚、东京、香港区域。文档明确**不支持 batch inference、fine-tuning、独立模型部署**。[^1][^2]
- **定价**：新加坡 International 价每百万输入 **$1.50**、输出 **$4.50**；北京/Global 文档价 **$1.413/$4.24**。新加坡有附条件的 100 万 token 免费额度；缓存单独计费。地区、缓存、思考输出与折扣口径不能混用。[^2]
- **官方 benchmark**：Alibaba 报 Code Arena 第 6，内部 Work360 721 领域测试中较 Qwen3.8-Max 在 high effort 下少用 35% tokens、平均单任务成本约降 60%。均属**厂商披露或厂商选择引用的榜单**，不是本研究独立复现。[^1]
- **安全/长程 Agent**：官方称训练中筛除攻击性网络安全数据并加强 CBRN 缓解；举 48 小时实验闭环、454 次工具调用等案例。只能写“厂商报告完成案例”，不能推导为普遍可靠、实际客户 ROI 或安全有效性。[^1]
